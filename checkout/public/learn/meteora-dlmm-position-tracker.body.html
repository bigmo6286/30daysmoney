Meteora DLMM position tracker

If you LP on Meteora and on Uniswap, you're probably checking two or three sites. The free LP PnL dashboard shows both in one view, read straight from the chain.

Open the free dashboard

Set it up (one minute)

  1. Solana's public RPC refuses requests from browsers, so the dashboard needs your own RPC URL. A free Helius key works. In the dashboard, open Settings and paste the RPC URL. It's stored only in your browser.
  2. Add your Solana wallet address.
  3. Each DLMM position shows its value in SOL (for SOL pairs), its unclaimed fees and whether the active bin is inside your range.

What it reads

Positions come from Meteora's own SDK: getAllLbPairPositionsByUser. Value is the tokens in your bins at the pool's current active-bin price, plus unclaimed fees. Nothing is estimated from an API that might lag. If a read fails, the dashboard says so instead of showing zero.

Automating DLMM positions

For positions that open, rebalance and close themselves, there's the DLMM Agent, a Telegram bot that runs on your own machine.

  • Screening is deterministic, with no LLM picking trades.
  • It starts in paper mode.
  • Every transaction is simulated first.
  • Stop loss is on by default.
  • Presets: safe, balanced or aggressive.

The free version does manual LP; Pro adds the autopilot.
